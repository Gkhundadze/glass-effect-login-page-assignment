# პრაქტიკული დავალება — Glassmorphism Login Page

## მიზანი

მოცემული Figma დიზაინის მიხედვით შექმენი ავტორიზაციის გვერდი (Login Page), გამოიყენე HTML და CSS.

დავალების მიზანია, ისწავლო დიზაინის ანალიზი, HTML სტრუქტურის სწორად ორგანიზება და CSS-ის საშუალებით თანამედროვე ვიზუალური ეფექტების შექმნა.

**დიზაინი:** [Glass Effect Login Page — Figma](https://www.figma.com/design/gyqGB00fFGL8r3U3f4wnOq/Glass-Effect-Login-Page--Community-?node-id=101-10073)

## 1. HTML სტრუქტურა

შექმენი გვერდი, რომელიც მოიცავს შემდეგ ელემენტებს:

- მთავარი კონტეინერი (Login Wrapper).
- ავტორიზაციის ბარათი (Login Card).
- ლოგოს განყოფილება.
- Login სათაური.
- Email ველი.
- Password ველი.
- Forgot Password ბმული.
- Sign In ღილაკი.
- Social Login ღილაკები (Google, GitHub, Facebook).
- რეგისტრაციის ბმული.

HTML-ის წერისას გამოიყენე სემანტიკური ელემენტები და შესაბამისი input ტიპები.

## 2. ძირითადი განლაგება

CSS-ის გამოყენებით შექმენი დიზაინის ძირითადი განლაგება.

მოთხოვნები:

- გვერდს უნდა ჰქონდეს ლურჯი ფონის დიზაინი.
- Login Card უნდა განთავსდეს ეკრანის ცენტრში.
- ბარათის შიგნით ელემენტები სწორად უნდა იყოს განლაგებული.
- გამოიყენე Flexbox განლაგებისთვის.
- დაიცავი ელემენტებს შორის დაშორებები.
- გამოიყენე შესაბამისი ზომები, ფერები და მომრგვალებული კუთხეები.

## 3. Glassmorphism ეფექტი

დავალების მთავარი ვიზუალური ნაწილია Glassmorphism.

Login Card-ს უნდა ჰქონდეს:

- გამჭვირვალე ფონი.
- Background Blur ეფექტი.
- მსუბუქი საზღვარი (Border).
- მომრგვალებული კუთხეები.
- ჩრდილი (Box Shadow).

გამოიყენე CSS-ის შესაბამისი თვისებები:

- `background`
- `backdrop-filter`
- `border`
- `box-shadow`
- `border-radius`
- `opacity`

ეცადე, ბარათმა შექმნას მინის ზედაპირის ეფექტი და ამავდროულად ტექსტი მკაფიოდ იკითხებოდეს.

## 4. ფორმის სტილიზაცია

გასტილე Email და Password ველები.

მოთხოვნები:

- ველებს უნდა ჰქონდეთ თეთრი ან ღია ფერის ფონი.
- გამოიყენე Placeholder.
- მოარგე ველების ზომები დიზაინს.
- დაამატე შესაბამისი დაშორებები.
- შექმენი Focus მდგომარეობა.
- Password ველს უნდა ჰქონდეს პაროლის ტიპი.

Sign In ღილაკს შეურჩიე მუქი ლურჯი ფონი და შესაბამისი Hover ეფექტი.

## 5. დამატებითი ელემენტები

დაამატე Social Login ღილაკები.

თითოეულ ღილაკში განათავსე შესაბამისი პლატფორმის ლოგო.

რეგისტრაციის ტექსტში გამოყავი Register ბმული განსხვავებული ფერით.

დიზაინში არსებული დეკორატიული ფორმები შეგიძლია შექმნა CSS-ის გამოყენებით ან გამოიყენო შესაბამისი გრაფიკული რესურსები.

## 6. Hover ეფექტები

დაამატე ინტერაქციის ვიზუალური ეფექტები:

- Sign In ღილაკზე Hover.
- Social Login ღილაკებზე Hover.
- Register ბმულზე Hover.
- Forgot Password ბმულზე Hover.

ეფექტები უნდა იყოს მსუბუქი და ბუნებრივი. საჭიროების შემთხვევაში გამოიყენე `transition` და `transform`.

## 7. დამატებითი გამოწვევა — Responsive Design

მოარგე გვერდი სხვადასხვა ეკრანის ზომას.

გაითვალისწინე:

- Login Card არ უნდა გასცდეს ეკრანის საზღვრებს.
- Input ველები უნდა ინარჩუნებდნენ სწორ ზომებს.
- გვერდის ელემენტები სწორად უნდა განლაგდეს მობილურ ეკრანზეც.
- შეამოწმე მინიმუმ 375px და 320px სიგანის ეკრანებზე.

## ჩაბარების პირობები

- პროექტი უნდა შეიცავდეს HTML და CSS ფაილებს.
- HTML და CSS კოდი უნდა იყოს მოწესრიგებული და სტრუქტურირებული.
- გამოყენებული უნდა იყოს CSS კლასები და არა Inline Styles.
- გვერდის ვიზუალი მაქსიმალურად უნდა შეესაბამებოდეს Figma დიზაინს.
- პროექტი უნდა იხსნებოდეს ბრაუზერში შეცდომების გარეშე.

**შენიშვნა:** ამ დავალებაში ავტორიზაციის რეალური ფუნქციონალის შექმნა საჭირო არ არის. მთავარი აქცენტი HTML სტრუქტურასა და CSS დიზაინზეა.
